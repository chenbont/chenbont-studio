# 使用说明

> 本文档仅描述已发布安装包的使用方法，不涉及任何源码。

## 一、安装

### Linux（.deb）
1. 从 [Releases](../) 下载 `Chenbont-Studio-0.1.56-amd64.deb`；
2. 安装：`sudo dpkg -i Chenbont-Studio-0.1.56-amd64.deb`（依赖缺失时执行 `sudo apt -f install`）；
3. 从应用菜单或终端 `chenbont-studio` 启动。

### Linux（AppImage）
1. 下载 `Chenbont-Studio-0.1.56-x86_64.AppImage`；
2. 赋予可执行权限：`chmod +x Chenbont-Studio-0.1.56-x86_64.AppImage`；
3. 双击或命令行运行。

### Windows / macOS
当前版本尚未发布 Windows / macOS 安装包，下载区显示「敬请期待」。发布后将在此补充说明。

## 二、首次启动

1. 启动后根据提示完成初始化设置；
2. 在**设置 → 模型**中配置你的 AI 模型（支持任意 OpenAI 协议 / Responses API 端点），底层模型由你自行配置；
3. 新建或打开会话即可开始 AI 辅助编程。内置功能包括：
   - **文件管理**：Monaco 编辑器（30+ 语言）、文件树、三态视图（编辑 / Diff / 预览）；
   - **Git**：多仓库管理、分支切换、历史、AI 生成提交信息、AI 解决合并冲突；
   - **终端**：多标签、项目切换不中断；
   - **浏览器预览**：多标签、元素拾取、agent 自动驱动；
   - **数据库管理**：SQLite / MySQL / PostgreSQL，支持 AI 自然语言生成 SQL；
   - **GitHub 集成**：浏览 / 合并 PR、管理 Issue；
   - **自动化定时任务**：一次性 / 间隔 / 每天 / 每周 / 每月 / cron。

## 三、手机远程访问

Chenbont Studio 提供三种手机远程访问方式：

1. **局域网**：桌面端在「远程访问」中生成通道二维码，手机扫描即可配对连接（设备令牌认证）；
2. **官方中继（零配置）**：桌面端生成二维码，手机扫码即连（免费层：1 台手机主控 + 1 个访客；Pro 支持更多设备，详见 [docs/中继服务定价.md](./中继服务定价.md)）；
3. **自托管 / SSH 隧道**：在自备服务器部署开源中继服务 Studio Relay（https://gitcode.com/chenbont/studio-relay ，需泛域名解析与 TLS），或自备 VPS 走 SSH 反向隧道。

手机端可看会话实时流、发消息、中断 / 撤销回合、审批工具调用、浏览文件与 diff、执行 Git 操作（含 AI 提交信息）。

> Studio Relay 为独立开源项目，部署与运维不在本闭源桌面端支持范围内。
> Studio Relay is a separate open-source project; its deployment is outside the scope of this closed-source desktop client.

## 四、升级与卸载

- **升级**：已内置自动更新（从 GitHub Releases 拉取），安装后通常无需手动升级；亦可在 Releases 下载新版本覆盖安装。
- **卸载**：Linux 执行 `sudo dpkg -r chenbont-studio`（或删除 AppImage），其他平台随发布补充。
