# 使用说明

> 本文档仅描述已发布安装包的使用方法，不涉及任何源码。

## 一、安装

### Linux（.deb）
1. 从 [Releases](../) 下载 `Chenbont-Studio-0.1.56-amd64.deb`；
2. 安装：`sudo dpkg -i Chenbont-Studio-0.1.56-amd64.deb`（依赖缺失时执行 `sudo apt -f install`）；
3. 从应用菜单或终端 `chenbont-studio` 启动。

### Linux（AppImage）
1. 下载 `Chenbont-Studio-0.1.56-x86_64.AppImage`；
2. 赋予可执行权限：`chmod +x Chenbont-Studio-0.1.56-x86_64.AppImage`；
3. 双击或命令行运行。

### Windows / macOS
当前版本尚未发布 Windows / macOS 安装包，下载区显示「敬请期待」。发布后将在此补充说明。

## 二、首次启动

1. 启动后根据提示完成初始化设置；
2. 在**设置 → 模型配置**中配置你的 AI 模型（支持任意 OpenAI 协议 / Responses API 端点）；可在同一页按角色为普通对话、AI 提交信息、合并冲突解决分配不同模型；
3. 新建会话时选择引擎（**Claude Code / Pi / Codex / OpenCode**），首次使用会自动下载对应的 agent 运行时，无需自装 CLI；
4. 新建或打开会话即可开始 AI 辅助编程。内置功能包括：
   - **文件管理**：Monaco 编辑器（30+ 语言）、文件树、三态视图（编辑 / Diff / 预览）、LSP 语言服务；
   - **Git**：多仓库管理、分支切换、历史、AI 生成提交信息、AI 解决合并冲突；
   - **终端**：多标签、项目切换不中断；
   - **浏览器预览**：多标签、设备模拟、元素拾取、agent 自动驱动；
   - **数据库管理**：SQLite / MySQL / PostgreSQL，支持 AI 自然语言生成 SQL；
   - **GitHub 集成**：浏览 / 合并 PR、管理 Issue；
   - **多 agent 编排**：可分解任务自动拆成多个子 agent 并行跑，任务图画布看进展；
   - **自动化定时任务**：一次性 / 间隔 / 每天 / 每周 / 每月 / cron。

## 三、手机远程访问

Chenbont Studio 提供两种手机远程控制方式，入口都在左侧边栏的**「远程控制」**：

1. **局域网**：在同一网络下，桌面端生成配对二维码与 6 位验证码，手机扫码（或输入配对 ID + 验证码）即可连接（设备令牌认证）；
2. **官方中继**：外网连接必须经 Chenbont 官方中继。在「远程控制 → 允许外部接入」面板里用**邮箱验证码登录**云端账号并开启开关，之后生成二维码给手机扫；连接优先 P2P 直连（不计费），无法穿透时由官方中继转发，中转流量每月含基础额度，超出部分按官方公布单价从钱包余额扣费，可在同一面板里的账号卡充值。不提供自托管中继或 SSH 隧道接入。

手机端可看会话实时流、发消息、中断 / 撤销回合、审批工具调用、浏览文件与 diff、执行 Git 操作（含 AI 提交信息）。已配对设备可以在面板中看在线状态并逐个断开。

> 云端中继服务由官方统一运维，用户无需自行部署服务器。
> The cloud relay is operated by the official team; no self-deployment is required.

## 四、升级与卸载

- **升级**：已内置自动更新（从 GitHub Releases 拉取），安装后通常无需手动升级；亦可在 Releases 下载新版本覆盖安装。
- **卸载**：Linux 执行 `sudo dpkg -r chenbont-studio`（或删除 AppImage），其他平台随发布补充。
