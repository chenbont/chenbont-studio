# Frequently Asked Questions (FAQ)

> Covers distribution and usage only — no source code or internal implementation.

## 1. Is this open source?
No. The Chenbont Studio **desktop app** is proprietary (closed-source). This repository provides documentation and release downloads only — no source code. Use is governed by the [LICENSE](../LICENSE). The companion cloud relay service **Studio Relay** is open source at https://gitcode.com/chenbont/studio-relay.

## 2. Download is slow or fails?
- Check your network or try again later.
- Some platforms rate-limit release bandwidth; retry after a while.
- Verify integrity with the `checksums.txt` shipped with each release.

## 3. Are the installers safe? Could antivirus flag them?
Our installers are built and signed/verified. Some antivirus products may false-positive; you may add the app to a whitelist. If unsure, do not install.

## 4. Which systems are supported?
See the "Supported Platforms" section in [README](../README.md). Linux (.deb and AppImage) is released; Windows / macOS are coming soon. Systems below the minimum requirement may not run.

## 5. Is it free?
Distributed free of charge. This repository is the official channel — beware of third-party resellers. Some advanced features or enterprise licensing may be paid; see official announcements.

## 6. Can I resell or redistribute it?
**No.** Without written permission, redistribution, resale, reverse engineering, or embedding in other products is prohibited. See [LICENSE](../LICENSE).

## 7. Where is my data? Is it uploaded?
Chenbont Studio runs locally; sessions and project data are stored on your machine by default. AI features connect to the model service you configure in Settings; data flow follows the app's in-product notices and each model provider's terms. The authors do not actively collect your code.

## 8. How do I enable phone remote access?
Self-host the open-source **Studio Relay** service on a server with wildcard DNS and TLS configured, then scan the QR code generated by the desktop app with your phone. See [usage.md](./usage.md).

## 9. How do I report bugs or suggestions?
Use https://gitcode.com/chenbont/studio-relay/issues and include the version and reproduction steps where possible.

## 10. Where do I get the latest version?
Watch the **Releases** page of this repository, or visit https://chenbont.com .
