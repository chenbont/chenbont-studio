# 官方中继服务定价方案

> 定稿于 2026-02。官方中继 = Studio Relay 的零配置托管版，与自托管开源中继永久免费并行。

## 定价结构

| 层 | 价格 | 内容 |
|---|---|---|
| **Free** | ¥0 | 1 台手机主控连接 + 1 个访客（只读 + 单次审批需主控确认），基础消息转发 |
| **Pro** | ¥10/设备/月 或 ¥100/设备/年（约 2 个月免费） | 更多设备、多访客、完整远程控制功能 |

## 设计原则

- **免费层 = 个人单人使用的最小真实场景**：1 主控 + 1 访客，长期免费而非限时试用
- **访客角色免费层只读为主**：看会话、看 diff；单次操作需主控确认——免费版天然安全，凸显 Pro 的多设备完整控制价值
- **不做功能阉割**：免费层只做连接数/频次限流，功能完整，避免口碑受损
- **升级路径清晰**：接第 2 台手机或第 2 个访客时，客户端内提示升级
- **年付引导**：¥100/年锁定现金流，减少月付流失

## 官方中继 vs 自托管

| | 官方中继 | 自托管（开源 Studio Relay） |
|---|---|---|
| 配置 | 扫码即用，零配置 | 自备服务器，自行部署维护 |
| 费用 | Free 层免费 / Pro ¥10/设备/月 | 服务器成本自担（VPS 约 ¥20–40/月） |
| 适用 | 个人、小团队、想省事的用户 | 私有化、内网、合规要求场景 |
