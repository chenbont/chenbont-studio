## 1. 这是开源软件吗？
不是。Chenbont Studio **桌面端**为专有（闭源）软件，本仓库仅提供说明文档与发行版下载，不提供源代码。使用受 [LICENSE](../LICENSE) 约束。软件基于开源项目 Mcode（MIT）二次开发，上游版权与许可声明见 [THIRD-PARTY-NOTICES.md](../THIRD-PARTY-NOTICES.md)。

## 2. 下载速度慢 / 下载失败怎么办？
- 请确认网络环境，或更换下载时段重试；
- 部分网络对 GitHub 访问受限，可尝试更换网络或使用代理；
- AppImage 下载后需 `chmod +x` 才有可执行权限；
- 校验文件完整性可比对各版本发行版附带的 `checksums.txt`。

## 3. 安装包安全吗？会被杀毒软件误报吗？
我们发布的安装包均经构建与 sha256 校验（`checksums.txt`），自动更新也校验签名与摘要。个别杀毒软件可能对 Electron 应用或未签名二进制误报，可将本软件加入白名单；如仍不放心，请勿安装使用。

## 4. 支持哪些系统？
见 [README](../README.md) 的「支持平台」一节。当前已发布 Linux（.deb 与 AppImage，x86_64），Windows / macOS 版本敬请期待。低于最低版本要求（如 glibc < 2.31）的系统可能无法运行。

## 5. 软件收不收费？
软件通过本仓库（官方渠道）获取，请警惕第三方转售。客户端本身可免费使用，**AI 能力由你自己配置的模型服务计费**，成本由你控制。外网远程连接统一经 Chenbont 官方中继并需登录云端账号：P2P 直连流量不计费，中继转发流量每月含基础额度，超出部分按官方公布单价从钱包余额扣费，可在远程控制面板充值。

## 6. 可以转卖或二次分发吗？
**不可以**。未经书面授权，禁止再分发、二次销售、逆向工程或嵌入其他产品，详见 [LICENSE](../LICENSE)。

## 7. 数据存在哪里？会不会上传？
Chenbont Studio 在本地运行，会话与项目数据默认保存在本机的应用数据目录：

- 会话、设置、快照等存于 SQLite 数据库 `chenbont-studio.db`（位于系统用户数据目录：Linux 为 `~/.config/Chenbont Studio/`，Windows 为 `%APPDATA%\Chenbont Studio\`，macOS 为 `~/Library/Application Support/Chenbont Studio/`）；
- 日志位于同目录下的 `logs/`；
- 引擎凭证与配置另存于 `~/.chenbont/`。

AI 功能需按你的模型设置连接相应模型服务；具体数据流向以软件内说明与各模型服务条款为准。作者不主动收集你的代码内容。使用官方中继时，中继仅转发密文、不落地存储明文。

## 8. 如何实现手机远程访问？
两种方式，入口都在左侧边栏的**「远程控制」**：
1. **局域网**：桌面端生成配对二维码与 6 位验证码，手机扫码（或输入配对 ID + 验证码）即可配对；
2. **官方中继**：所有外网连接必须经官方中继，需在「远程控制 → 允许外部接入」面板里用邮箱验证码登录云端账号并开启开关；连接优先 P2P 直连，无法直连时由官方中继转发，中转流量每月含基础额度，超出部分按官方公布单价从钱包余额扣费。不提供自托管中继或 SSH 隧道接入。

已配对设备可在面板中查看在线状态并逐个断开。详见 [使用说明](./使用说明.md)。

## 9. 需要单独安装 CLI / agent 运行时吗？
不需要。agent 运行时（Pi / Claude Code / Codex）由 Chenbont Studio 首次使用时自动下载，无需自装 CLI；运行时组件随插件与模型配置一同管理（**设置 → 插件**）。首次使用引擎时请保持网络畅通，下载完成前该引擎不可用。

## 10. 可以用哪些模型 / 引擎？
在**设置 → 模型配置**中配置任意 OpenAI 协议 / Responses API 端点即可使用自有模型，并可按角色（普通对话、AI 提交信息、合并冲突解决）分配不同模型；同时内置 **Claude Code / Pi / Codex / OpenCode** 多引擎支持，按会话切换。API Key 经 Electron `safeStorage` 加密存储（受系统钥匙串保护）。

## 11. 一定要有 API Key 吗？能用本地模型吗？
需要。软件本身**不内置**任何模型额度或中转密钥，必须由你提供模型端点与密钥。只要你的端点兼容 OpenAI 协议 / Responses API，本地部署的推理服务（如 Ollama、vLLM 等配套的兼容网关）同样可以填入使用，速度与效果取决于本地硬件与所选模型。

## 12. 支持哪些界面语言？
12 种：简体中文、English、العربية（阿拉伯语）、Deutsch（德语）、Español（西班牙语）、Français（法语）、Bahasa Indonesia（印尼语）、日本語、한국어（韩语）、Português（葡萄牙语）、Русский（俄语）、Tiếng Việt（越南语）。可在**设置 → 常规 → 界面语言**中切换，修改后立即生效。

## 13. 如何升级？
内置自动更新（electron-updater）：启动后延迟检查一次，此后每约 4 小时检查一次 GitHub Releases；**默认不自动下载**，在**设置 → 关于**中点击下载、待进度完成后再选择「重启并安装」。也可以直接从 Releases 下载新版本覆盖安装，用户数据与设置会保留。

## 14. 如何备份 / 迁移 / 彻底卸载？
- **备份 / 迁移**：**完全退出软件**后，复制系统用户数据目录（见第 7 条，含 `chenbont-studio.db`）与 `~/.chenbont/` 到新机器对应位置即可。
- **卸载（Linux .deb）**：`sudo dpkg -r chenbont-studio`；AppImage 直接删除文件；其他平台随发布补充。
- **彻底清理**：卸载后手动删除用户数据目录与 `~/.chenbont/`，否则重装会沿用旧配置与会话。

## 15. 遇到崩溃或异常怎么排查？
1. 确认已升级到 Releases 中的最新版本；
2. 打开 **设置 → 关于** 查看版本号，并收集用户数据目录下 `logs/` 里的当日日志；
3. 若是某个引擎或语言服务器异常，可先禁用/重装对应运行时或插件再试；
4. 若与手机远程有关，先确认局域网直连是否可用，再排查中继账号与流量额度。

反馈时请附上版本号、操作系统、复现步骤与相关日志片段。
