# 常见问题（FAQ）

> 以下仅覆盖发行与使用层面的常见问题，不涉及源码或内部实现。

## 1. 这是开源软件吗？
不是。Chenbont Studio **桌面端**为专有（闭源）软件，本仓库仅提供说明文档与发行版下载，不提供源代码。使用受 [LICENSE](../LICENSE) 约束。与之配套的云端中继服务 **Studio Relay** 是开源项目（https://gitcode.com/chenbont/studio-relay）。

## 2. 下载速度慢 / 下载失败怎么办？
- 请确认网络环境，或更换下载时段；
- 部分平台对发行版有带宽限制，可稍后重试；
- 校验文件完整性可比对各版本的 `checksums.txt`。

## 3. 安装包安全吗？会被杀毒软件误报吗？
我们发布的安装包均经过构建与签名/校验。个别杀毒软件可能误报，可将本软件加入白名单；如仍不放心，请勿安装使用。

## 4. 支持哪些系统？
见 [README](../README.md) 的「支持平台」一节。当前已发布 Linux（.deb 与 AppImage），Windows / macOS 版本敬请期待。低于最低版本要求的系统可能无法运行。

## 5. 软件收不收费？
免费分发。本仓库下载为官方渠道，请警惕第三方转售。部分高级功能（如官方中继 Pro、企业授权）可能另行收费，以官方公告为准。

## 6. 可以转卖或二次分发吗？
**不可以**。未经书面授权，禁止再分发、二次销售、逆向工程或嵌入其他产品，详见 [LICENSE](../LICENSE)。

## 7. 数据存在哪里？会不会上传？
Chenbont Studio 在本地运行，会话与项目数据默认保存在本机。AI 功能需按你的模型设置连接相应模型服务；具体数据流向以软件内说明与各模型服务条款为准。作者不主动收集你的代码内容。使用官方中继时，中继仅转发密文、不落地存储明文。

## 8. 如何实现手机远程访问？
三种方式：
1. **局域网**：桌面端生成二维码，手机扫码配对；
2. **官方中继**：零配置扫码即用（免费层：1 主控 + 1 访客；Pro 见 [中继服务定价](./中继服务定价.md)）；
3. **自托管**：部署开源的 Studio Relay（泛域名 + TLS），或自备 VPS 走 SSH 反向隧道。
详见 [使用说明](./使用说明.md)。

## 9. 需要单独安装 CLI / agent 运行时吗？
不需要。agent 运行时（Pi / Claude / Codex）由 Chenbont Studio 首次使用时自动下载，可在**设置 → 运行时**中管理。

## 10. 可以用哪些模型 / 引擎？
在**设置 → 模型**中配置任意 OpenAI 协议 / Responses API 端点即可使用自有模型；同时内置 **Claude / Pi / Codex / OpenCode** 多引擎支持，按会话切换。API Key 经系统安全存储加密。

## 11. 如何反馈 Bug 或建议？
通过 https://github.com/chenbont/chenbont-studio/issues 反馈，并尽量附上版本号与复现步骤。

## 12. 在哪里获取最新版本？
关注本仓库的 **Releases** 页面，或访问官方网站 https://chenbont.com 。
