# 常见问题（FAQ）

> 以下仅覆盖发行与使用层面的常见问题，不涉及源码或内部实现。

## 1. 这是开源软件吗？
不是。Chenbont Studio **桌面端**为专有（闭源）软件，本仓库仅提供说明文档与发行版下载，不提供源代码。使用受 [LICENSE](../LICENSE) 约束。

## 2. 下载速度慢 / 下载失败怎么办？
- 请确认网络环境，或更换下载时段；
- 部分平台对发行版有带宽限制，可稍后重试；
- 校验文件完整性可比对各版本的 `checksums.txt`。

## 3. 安装包安全吗？会被杀毒软件误报吗？
我们发布的安装包均经过构建与签名/校验。个别杀毒软件可能误报，可将本软件加入白名单；如仍不放心，请勿安装使用。

## 4. 支持哪些系统？
见 [README](../README.md) 的「支持平台」一节。当前已发布 Linux（.deb 与 AppImage），Windows / macOS 版本敬请期待。低于最低版本要求的系统可能无法运行。

## 5. 软件收不收费？
软件通过本仓库（官方渠道）获取，请警惕第三方转售。外网远程连接统一经 Chenbont 官方中继并需登录云端账号：P2P 直连流量不计费，中继转发流量每月含基础额度，超出部分按官方公布单价从钱包余额扣费，可在远程连接面板充值。

## 6. 可以转卖或二次分发吗？
**不可以**。未经书面授权，禁止再分发、二次销售、逆向工程或嵌入其他产品，详见 [LICENSE](../LICENSE)。

## 7. 数据存在哪里？会不会上传？
Chenbont Studio 在本地运行，会话与项目数据默认保存在本机。AI 功能需按你的模型设置连接相应模型服务；具体数据流向以软件内说明与各模型服务条款为准。作者不主动收集你的代码内容。使用官方中继时，中继仅转发密文、不落地存储明文。

## 8. 如何实现手机远程访问？
两种方式，入口都在左侧边栏的**「远程控制」**：
1. **局域网**：桌面端生成配对二维码与 6 位验证码，手机扫码（或输入配对 ID + 验证码）即可配对；
2. **官方中继**：所有外网连接必须经官方中继，需在「远程控制 → 允许外部接入」面板里用邮箱验证码登录云端账号并开启开关；连接优先 P2P 直连，无法直连时由官方中继转发，中转流量每月含基础额度，超出部分按官方公布单价从钱包余额扣费。不提供自托管中继或 SSH 隧道接入。
详见 [使用说明](./使用说明.md)。

## 9. 需要单独安装 CLI / agent 运行时吗？
不需要。agent 运行时（Pi / Claude Code / Codex）由 Chenbont Studio 首次使用时自动下载，无需自装 CLI；运行时组件随插件与模型配置一同管理（**设置 → 插件**）。

## 10. 可以用哪些模型 / 引擎？
在**设置 → 模型配置**中配置任意 OpenAI 协议 / Responses API 端点即可使用自有模型，并可按角色（普通对话、AI 提交信息、合并冲突解决）分配不同模型；同时内置 **Claude Code / Pi / Codex / OpenCode** 多引擎支持，按会话切换。API Key 经 Electron `safeStorage` 加密存储。
